# Исходники сайта hi-sisters.clinic

Страницы сайта не пишутся руками: их собирает `src/build.py` из данных в `src/content/`.

- `src/content/*.json` — весь текст, цены, услуги, курсы, отзывы, каталог косметики.
- `src/build.py` — генератор: из данных делает готовые HTML-страницы на пяти языках.
- `src/_check.py` — проверка сборки: битые ссылки, пустые заголовки, навигация.
- `assets/` в корне — фотографии, их генератор не трогает.

Как только меняется что-то в `src/`, GitHub сам пересобирает сайт и выкладывает
обновлённые страницы в корень репозитория (см. `.github/workflows/build.yml`).
Собранные страницы попадают в корень; папка `src/site/` — временная, в репозиторий не идёт.
