Hi Sisters — панель управления

Вход

Нужен личный ключ доступа GitHub с правом записи в репозиторий сайта. Ключ хранится только в этом браузере и отправляется только на github.com.

Где взять: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: только hi-sisters-website → Permissions → Repository permissions → Contents: Read and write.

Что редактируем
